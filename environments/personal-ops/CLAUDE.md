# Claude notes

This file loads automatically when Claude works in this vault. It adds Claude-specific mechanics only — **[[AGENTS]] is the operating manual and takes precedence**; [[README]] defines structure and naming. Read both before your first write of a session.

- Prefer targeted edits over full-file rewrites for existing notes — it preserves properties and text you weren't asked to change (AGENTS rule 5).
- Re-read a note just before editing it rather than working from a copy fetched earlier in a long conversation; the vault syncs and the owner edits live.
- After editing frontmatter, confirm it still parses as YAML: an unquoted `[[wikilink]]`, an unquoted `HH:MM` time, or a stray colon in a value silently breaks a note's properties.
- In cloud/Cowork sessions, a written file only reaches the vault when explicitly committed back to the connected folder — verify the write landed before logging it as done.
- Don't "improve" doc wording, structure, or other agents' log entries while doing an unrelated task (AGENTS rules 4–5, 7).
- Before ending any session that changed the vault, append your `## Log` line(s) to today's daily note (AGENTS: Procedures).
